# Monte Carlo Pricing of Barrier Options

Developed by Thomas Sylvest Kirk. This project implements several Monte Carlo approaches for pricing discretely monitored down-and-out call options in MATLAB.

The project compares different estimators and evaluates their statistical and computational properties, including:

* Euler discretization
* Brownian Bridge estimators
* ABAST barrier corrections
* Control variate techniques for variance reduction
* Finite-difference estimation of option sensitivities (Greeks)

The analysis investigates estimator bias, variance reduction, computational efficiency, and the sensitivity of option prices to changes in volatility and barrier levels.

Key topics:

* Monte Carlo simulation
* Exotic option pricing
* Barrier options
* Variance reduction techniques
* Numerical methods in derivatives pricing
* Quantitative finance
